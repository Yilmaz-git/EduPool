\# EduPool



EduPool is a web-based educational content sharing platform developed with PHP and MySQL.



\## Features

\- User authentication

\- Notes, videos and question sharing

\- File upload system

\- Project sharing

\- Like system

\- Filtering by lesson and content type



\## Technologies

\- PHP

\- MySQL

\- HTML/CSS

\- JavaScript

\- WampServer



\## Installation

1\. Import `edu\_pool.sql`

2\. Put project folder inside `wamp64/www`

3\. Start Apache and MySQL

4\. Open in browser after starting Apache and MySQL:
http://localhost/edupool
